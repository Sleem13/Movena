# Sprint 1.5 Dataset Pipeline Validation

## Sprint 1.5 Goal

Sprint 1.5 validates the data pipeline foundation for PhysioVision AI without training a model. The goal is to keep three paths cleanly separated:

- Camera/video-based exercise analysis.
- Wearable sensor-based exercise analysis.
- Future multimodal fusion.

The current Sprint 1 squat video analyzer must keep working while dataset utilities mature around it.

## Raw Data Policy

Raw datasets are local-only. Do not commit raw videos, public dataset downloads, participant files, UCI sensor files, or generated dataset artifacts to GitHub.

Raw folders should contain manually downloaded or consented local data:

- `data/raw/custom_videos/` for PhysioVision camera recordings.
- `data/raw/squat_kaggle/` for squat-specific public data.
- `data/raw/uci_physical_therapy_exercises/` for UCI wearable-sensor time-series data.
- Future rehab datasets under their named folders.

## Processed Data Policy

Processed data is generated by scripts and should be reproducible from raw local data. Large CSV, JSON, or Parquet outputs should not be committed.

Expected outputs:

- `data/processed/pose_landmarks/` for MediaPipe landmark CSV files.
- `data/processed/angle_features/` for frame-level joint angle CSV files.
- `data/processed/sensor_features/` for UCI processed sensor rows and window features.
- `data/processed/merged_features/` reserved for future multimodal fusion.
- `data/processed/labels/` for normalized labels and metadata.

## Camera Pipeline

Input:

- `data/samples/`
- `data/raw/custom_videos/`

Scripts:

- `scripts/extract_landmarks_from_videos.py`
- `scripts/create_angle_features.py`

Outputs:

- `data/processed/pose_landmarks/*.csv`
- `data/processed/angle_features/*.csv`

This pipeline supports MediaPipe landmarks, joint angle calculation, rep counting research, and movement quality scoring validation.

## Sensor Pipeline

Input:

- `data/raw/uci_physical_therapy_exercises/`

Scripts:

- `scripts/prepare_uci_physical_therapy_dataset.py`
- `scripts/extract_sensor_features.py`

Outputs:

- `data/processed/sensor_features/uci_physical_therapy_exercises_processed.csv`
- `data/processed/sensor_features/uci_sensor_window_features.csv`

This pipeline supports wearable-sensor exercise classification, execution style classification, and time-series baseline features.

## Validation Checklist

- Run `python scripts/check_dataset_structure.py --create`.
- Confirm raw dataset folders are present.
- Confirm raw data remains ignored by Git.
- Run UCI preparation only after UCI files are downloaded locally.
- Run sensor feature extraction after processed UCI CSV exists.
- Run camera landmark extraction only after local videos exist.
- Run angle feature generation after landmark CSV files exist.
- Run backend tests to confirm the squat MVP still works.

## Known Limitations

- No models are trained in Sprint 1.5.
- The UCI dataset is not a video dataset and cannot validate MediaPipe landmarks.
- Camera and sensor features are intentionally not merged yet.
- Public datasets do not prove real-world clinical performance.
- UCI execution labels inferred from folder codes should be verified against the dataset documentation before model training.

## Future Multimodal Plan

Future sprints may align camera and sensor features by subject, exercise, repetition, or timestamp. The reserved `data/processed/merged_features/` folder exists for that later work. Fusion should happen only after camera and sensor pipelines are independently validated.
