# Sprint 31P — Product Hardening Before Closed Pilot

## Objective

Prepare Movena for controlled closed pilot readiness by strengthening privacy, safety, monitoring, and operational workflows.

## Current Status

Private staging deployment is complete.

Backend, database, frontend, and mobile validation have passed.

## Scope

1. Privacy and safety notice
2. Consent workflow preparation
3. User data deletion/export process
4. Closed pilot onboarding assets
5. Monitoring and issue tracking
6. Final mobile smoke checklist
7. Deployment documentation cleanup

## Out of Scope

- Public production launch
- Clinical deployment
- Real patient data collection
- Diagnosis or treatment prescription
- Large-scale user onboarding

## Acceptance Criteria

- Privacy and safety notice completed.
- Product hardening checklist completed.
- Closed pilot documents prepared.
- Deployment status documented.
- GitHub repository updated.
- No secrets committed.
- Backend/mobile/frontend tests remain passing.

## Decision Target

GO/NO-GO for controlled closed pilot preparation.
