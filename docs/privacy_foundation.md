# Privacy Foundation

Development/demo environments use synthetic or non-identifiable data. Session history is analysis metadata—not a medical record—and the therapist dashboard is a prototype.

Production requires identity, role authorization, consent/withdrawal, purpose limitation, encrypted secrets and transport, secure database/media storage, audit logging, retention/deletion/export controls, incident response, and privacy/legal review. Password hashes and secrets are never returned or logged.

AI output supports exercise monitoring and education only. It does not diagnose, prescribe treatment, or replace licensed physiotherapy assessment.
