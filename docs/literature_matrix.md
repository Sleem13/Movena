## Matrix Synthesis

Across these studies, the literature supports a focused MVP that uses markerless pose estimation for accessible measurement, but it also warns against overclaiming clinical accuracy. The strongest evidence for PhysioVision AI is the convergence of pose-estimation feasibility, rehabilitation exercise scoring research, and demand for remote monitoring. The main unresolved issue is translation into a therapist-centered, clinically safe workflow for lower-limb rehabilitation.
