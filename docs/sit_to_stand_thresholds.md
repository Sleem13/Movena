# Sit-to-Stand Engineering Thresholds

These values are configurable starting points for engineering evaluation. They are not normative clinical cutoffs and have not been clinically validated.

| Parameter | Default | Purpose |
|---|---:|---|
| Sitting knee angle maximum | 110° | Identify a seated or near-seated phase |
| Sitting hip angle maximum | 120° | Support seated-phase confirmation |
| Standing knee angle minimum | 155° | Identify near-standing knee extension |
| Standing hip angle minimum | 150° | Identify near-standing hip extension |
| Trunk lean warning | 35° | Educational trunk-control observation |
| Excessive trunk lean | 50° | Stronger trunk-control observation |
| Minimum rep duration | 1.0 s | Reject implausibly fast cycles |
| Maximum rep duration | 10.0 s | Bound incomplete/paused cycles |
| Minimum angle delta | 35° | Reject tiny or static movement |
| Minimum phase frames | 3 | Suppress single-frame transitions |
| Minimum frames between reps | 10 | Reduce double counting |
| Minimum pose detection rate | 0.50 | Reject poor body coverage |
| Minimum critical visibility | 0.50 | Require usable key-joint visibility |

Threshold changes require versioned test evidence and PT-informed review. They must not be presented as diagnostic or clinical-performance standards.
