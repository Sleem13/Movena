# Consent Workflow Plan

A future workflow will present versioned purpose, data categories, processing, retention, sharing, withdrawal, and contact information before capture or persistence. Acceptance records type, version, timestamp, and state without clinical details. Declining optional persistence should not block analysis where policy permits.

Withdrawal prevents new processing and triggers reviewed deletion/retention behavior. Guardianship, research consent, regional requirements, and clinic authority need legal/privacy review. The Sprint 13 consent model is a placeholder, not production consent.
