# External Beta Second-Wave Feedback Protocol

Feedback collection is inactive until the second-wave GO gate passes. Record only genuine, consented, privacy-safe submissions tagged `beta_wave=second`.

Capture alias, build, device/OS, supported exercise, upload outcome, analysis status, general/rejected-result clarity, confidence clarity, camera guidance, disclaimer visibility, limitations understanding, issue type/severity, and suggested improvement. Never request diagnosis, health history, patient identity, or patient media.

Review daily during an active wave. Escalate any privacy/safety concern immediately and stop affected testing. Empty records must remain `not_available`, never converted to success metrics.
