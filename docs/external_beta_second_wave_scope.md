# External Beta Second-Wave Scope

This scope is proposed only and cannot activate before a recorded GO/CONDITIONAL GO.

| Item | Controlled scope |
|---|---|
| Target size | Maximum 5–10 trusted, non-clinical adult testers; start with 5 |
| Eligibility | Able to consent, use non-identifying self-created/test media, follow safety/privacy instructions, and report product behavior |
| Excluded | Real patients, patient caregivers testing care, minors, anyone seeking diagnosis/treatment, anyone using identifiable patient media |
| Exercises | `bodyweight_squat`, `sit_to_stand`, `knee_extension`, `shoulder_abduction`, `hip_abduction` only |
| Duration | Proposed 5–7 days after all gates pass |
| Required tasks | At least 2 supported exercises, one invalid/static case, one safe retry/network case, result/rejection/camera-guidance/limitations checks |
| Success | Consented completion, safe rejection/no fake score, understandable results, acceptable upload reliability, no unresolved P0/P1 |
| Stop | Patient data, privacy/artifact exposure, diagnostic wording, fake score, launch crash, majority upload failure, or unsafe interpretation |

No public launch, real patient data, clinical use, or clinical claims are allowed.
