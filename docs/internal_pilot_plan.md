# Internal Pilot Plan

Status: blocked pending private staging deployment, Android build, physical-device QA, and privacy/security gate closure.

Scope is a small named internal engineering/product group using synthetic or personally created non-identifying test videos. Sessions are controlled, time-limited, and for usability/reliability evaluation only. No patients, clinical care, diagnosis, treatment decisions, or model promotion are allowed.

Before entry, verify signed onboarding/consent acknowledgment, approved device/build, staging account, supported exercise instructions, test-data rules, safety stop guidance, support contact, and issue-reporting route. Run the five supported exercises and assigned failure scenarios. At exit, revoke access where appropriate, collect the feedback form, triage all safety/privacy items immediately, and delete test artifacts according to retention.

Stop the pilot for unauthorized access/data, artifact exposure, misleading score/rejection, missing disclaimer, serious upload/auth failure, or any safety/clinical-claim concern.
