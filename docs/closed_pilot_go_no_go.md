# Closed Pilot Go/No-Go Decision

## Current Decision

- **NO-GO for public release.**
- **GO only for private staging review and closed pilot preparation.**

Movena has completed its private controlled staging release and is suitable for internal review, private demonstrations, and controlled non-clinical testing preparation. This decision does not authorize a public production release, clinical use, diagnosis, treatment prescription, external beta completion claims, or use of real patient data.

## Required Before Closed Pilot

- [ ] Privacy and safety notice completed.
- [ ] Consent workflow prepared.
- [ ] Tester onboarding document prepared.
- [ ] Feedback collection process prepared.
- [ ] Issue reporting process prepared.
- [ ] Mobile smoke test completed.
- [ ] Backend, mobile, and frontend tests passed.
- [ ] No secrets committed to GitHub.

## Required Before Public Release

- [ ] Real closed pilot feedback collected.
- [ ] Critical issues resolved.
- [ ] Privacy policy finalized.
- [ ] Terms and disclaimer finalized.
- [ ] Data deletion and export workflow implemented.
- [ ] Monitoring and incident response prepared.
- [ ] Security review completed.
- [ ] Movena trademark/domain clearance completed before public branding.
- [ ] External model code, weights, datasets, and redistribution rights cleared;
      model cards and independent Movena validation completed before enablement.

Completion of private staging validation does not satisfy these public-release requirements. A separate evidence-based GO/NO-GO review is required before any public release.
